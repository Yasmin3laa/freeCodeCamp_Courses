## 📚 Courses & Projects

### 🗄️ Relational Databases

Projects and exercises focused on relational database concepts using **PostgreSQL** and **SQL**.

#### 🌌 Celestial Bodies Database

A PostgreSQL relational database that models galaxies, stars, planets, moons, and comets.

**Topics covered:**

* PostgreSQL
* SQL
* Relational database design
* Primary keys
* Foreign keys
* Unique constraints
* One-to-many relationships
* Database sequences
* SQL `JOIN` operations

**Repository:**
[Celestial Bodies Database](https://github.com/Yasmin3laa/celestial-bodies-database)
